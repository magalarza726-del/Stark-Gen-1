# Changelog

## 1.0.0 — Reinicio Gen 1

- Eliminadas las funciones experimentales anteriores.
- Eliminado ARCore y el seguimiento de lápices genéricos.
- Nuevo tracker exclusivo de azul sobre fondo blanco o uniforme.
- Calibración corta de matiz y tamaño de la tapa.
- Seguimiento por componentes conectados y continuidad temporal.
- Tap-to-focus y botón de reenfoque.
- Nueva interfaz Stark Gen 1 con pantalla de inicio, menú, tutorial, calibración y dibujo.
- Herramientas mínimas: Selección, Dibujar, Borrar y Limpiar.
- Pipeline de GitHub Actions para publicar el APK.

- CI inicial activado para generar APK descargable desde GitHub.
